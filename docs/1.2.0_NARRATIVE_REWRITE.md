# Chronicle prose revision — RC.10

The chronicle now starts with the event itself. It no longer adds a stock chronicler introduction or an Ethos motto to every entry. Date, event title, perspective and cultural caption remain in the reading interface.

## Editorial rules

- English and Turkish have three separately written bodies for every event form, covering all 14 kinds, both sides of shared military events and new-building versus upgrade commissions.
- Ethos occasionally changes a verb or a short expression inside a founding, declaration or peace entry. It does not dictate a repeated closing sentence, add a moral or invent a cause. Most entries use ordinary factual language.
- Accepted commissions describe an order, completed construction describes finished work, and shipments describe received goods. Strategic engagements never invent physical casualties or battlefield details.
- Personal/place/building names remain literal. Turkish uses grammatical noun phrases where arbitrary names would otherwise require guessed suffixes. Known building names are quoted directly.
- Cultural identity remains in the localized caption; prose does not add the same ceremonial introduction to every event.
- Variant selection remains deterministic for the same immutable event and perspective. Language changes and restarts do not change dates, participants, source operations or saved facts.

## Language scope and compatibility

The EN/TR bodies and headings are rewritten. All 26 supported locales stop appending the old preamble/motto. The other 24 locales retain their existing localized event bodies under the new presentation keys; their additional sentence-level editorial revisions still need native-language work. They receive no new English fallback.

All1397 previous catalog values remain intact in every locale for older resource keys. The current narrator resolves 89 new compact-presentation keys per locale. Saved events remain format 1; old events receive the revised presentation when read, without rewriting the history store. Network and gameplay persistence are unchanged. The previously staged 1.2.0 artifact remains preserved; this revision is packaged separately as 1.2.0-rc.10.
