# Millénaire Kingdoms 1.2.0 — release preparation

The 1.2.0 build is being prepared on `feature/1.2.0-by-royal-decree`, using the existing Draft PR3. Stable publication and merging remain separate steps. Previous JARs and raw verification evidence are retained.

## Changes

- Political atlas pages exclude native `loneBuilding` types, including occupied small structures and ruins, as well as unknown types and records without buildings. The same filter applies to member lists and current-structure historical pins. Genuine native villages, including village-type hamlets, remain eligible. Discovery history and privacy are preserved; the filter never loads chunks.
- New natural capitals develop all generated buildings to their own final native plan levels. Targeted original 9.0.3 rush upgrades preserve native prerequisites, origin/ground adjustment, sub-buildings and completion effects. The bounded generation pass adds no unrelated layout projects. Existing worlds receive no retroactive building replacement. Capital chance 10% and spacing 1000 remain unchanged.
- Shipment retained stock is `min(50, max(native protection, construction + target + household needs, configured minimum))` per ordinary product. This includes older configured minimums above 50. Raw needs stay visible in the tooltip, while the effective retained quantity never exceeds 50. Physically missing/custom goods, currency, ownership, payment, capacity and unloaded-storage checks remain enforced.
- Documentation contains product rules and reproducible fixtures, without individual save reports or conversational attribution.

The stock cap intentionally permits sending materials beyond a village's larger construction/target needs. Its native builders may then wait for replenishment. A valid order still needs actual transferable physical items and normal authorization/payment; an unavailable destination retains cargo for later delivery.

Synchronous financial persistence latency and translation-quality limits from the RC.9 report remain applicable.
