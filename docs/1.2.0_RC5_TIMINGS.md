# RC.5 — natural capitals and decision timing / Doğal başkentler ve karar süreleri

The final user instruction is **durations only** after the explicit natural-capital chance/distance changes. Probability values and relation/townhall/reputation thresholds keep their existing values. The existing one-day calendar and Minecraft tick length are unchanged; halving uses each setting's native unit and rounds down (3 days → 1, 7 days → 3).

Joining remains part of the shared political round, so joining/war/peace/campaign selection use the one-day default. Its measured base chance stays 10%, joining relation +50, war relation −70, and founding level 3 / 5% +5 points per level. Personality weights, actual-fund/reserve/share safeguards and native military readiness are unchanged. Construction/shipment observation, actual cargo travel, financial receipts, UI offers, income and error-log backoff are separate mechanisms and keep their existing behavior.

## Existing worlds / Mevcut kayıtlar

NeoForge keeps the active `millenairekingdoms-server.toml` values. The ordinary server fixture uses `config/millenairekingdoms-server.toml`; also check the world's `serverconfig/` location when that is where the existing installation stores server configuration. Installing the new JAR does not replace already configured3/7/10-day values. To apply the new defaults to an existing world, update **only the matching keys in its existing sections** from [the partial gameplay settings](../releases/1.2.0-rc.5/serverconfig-changes.toml). This is a partial list, not a replacement for the entire file.

Türkçe: Yeni JAR'a ek olarak mevcut kurulumun kullandığı `millenairekingdoms-server.toml` dosyasındaki ilgili anahtarları verilen değerlerle güncelleyin (`config/` veya dünya içindeki `serverconfig/` konumunu kontrol edin); diğer ayarları koruyun, aynı başlığı ikinci kez eklemeyin ve dosyanın tamamını bu kısmi listeyle değiştirmeyin.

The three NPC peace-age constants and new conquest-order timing are implemented in the addon. Already persisted decision dates, economic cooldowns, active truces and existing order due/expiry times are retained; the new defaults govern future scheduling and new orders/truces. Existing villages/capitals are neither moved nor rerolled; 10% applies only to eligible newly generated natural villages. No source dependency, save schema or cloud setup/start instructions are changed. RC.3 Rulership navigation and RC.4 bilingual temperament names remain available.

Exact verification and artifact provenance are recorded in [the focused evidence](../verification/1.2.0/rc.5-timings/README.md); historical full-regression/simulation results are not a new RC.5 matrix claim.
