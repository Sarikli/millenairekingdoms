# Chronicle narrative style

The deterministic narrator presents immutable events; it cannot call gameplay services, external AI or the Internet. Event ID and participant ID choose one of three stable variants. English and Turkish use distinct prose rather than suffixing translated debug strings.

All13 event types have literary accounts. Shared wars and conquests retain factual direction while changing the viewpoint. Five ethos affect interpretative emphasis; seven culture-specific opening registers and tradition captions avoid treating every settlement as a European royal court. Generic language asserts no invented insult, border outrage, conversation, ceremony, named NPC or battle detail. Actor names appear only if the authoritative event knows them. Construction acceptance and genuine completion remain different stories; investments do not create another building.

Historical names are inserted literally, with no executable interpolation. Turkish uses noun phrases such as `İznik adlı krallık` and `Aşağıköy yerleşimi`, avoiding guessed suffixes for arbitrary generated names. Story facts/outcomes, event dates and historical locations are separate UI metadata; current ownership is never presented as old borders.

Presentation tests use synthetic event inputs only. Separate-JVM stable prose does not prove autonomous gameplay; real political/native construction hooks have independent runtime gates. Review the actual English/Turkish samples and perform graphical readability/scaling checks manually when a client is available.


The visible heading is **Ethos** in English and **Töre** in Turkish. Five corresponding labels remain Warlike/Savaşçı, Traditionalist/Gelenekçi, Peaceful/Barışçıl, Industrious/Üretken, Pragmatic/Pragmatik. The rename changes no policy weights or capital-type classification. A true building name is included when recorded; an unknown name remains a neutral village-building phrase. Peace prose closes the recorded war without claiming every surviving border was a war conquest.

Example from genuine construction facts (names vary by original plan): an accepted commission says the mandate was accepted and labour/materials still belong to village builders; only the separate completed event says the work was finished. A shipment in transit has no delivered chronicle. Cultural registers and ethos are interpretation, never extra factual causes. Automated fixtures check13 kinds, seven cultural registers, five ethos and distinct shared-war/conquest perspectives in both languages; actual spawned-world/native-builder results are documented separately.
