# Political atlas

The atlas displays discovered native villages and their current political identity. Native lone buildings, occupied small outposts, ruins, unknown types and records without buildings are excluded on the server before totals, pagination and revision calculation. Native village-type hamlets remain villages. Current member lists and current-structure history pins use the same filter.

Each kingdom has a persistent marker/name color; the capital receives a crown in that color. Neutral villages use a neutral color. Native village-type item icons, separate village/kingdom name lines, collision-aware labels and selection identify settlements. Influence polygons, territorial borders and ocean geography processing are removed.

Default discovery requires an already loaded settlement within512 horizontal blocks. Current ruler members and locally owned villages are also known. Strict format1 per-player/per-dimension discovery preserves learned identities, including older hidden structures; filtering never deletes saved knowledge or forces terrain. `revealAllRegisteredSettlements` is an explicit server opt-in and still applies the political-village filter.

The server sends bounded128-site pages from one revision, with a maximum8192 visible villages. Client assembly retains the last complete map during refresh. Missing replies time out after200 client ticks. Pan/zoom reuse available metadata. Economy is sent only to the current ruler; unknown historical coordinates stay redacted. Dated historical village pins are separate from current ownership.
