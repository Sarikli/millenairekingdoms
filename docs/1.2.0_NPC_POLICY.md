# NPC economic policy — Phase6 in progress

## Implemented preferences and existing political draws

RoyalInvestmentPolicy explicitly classifies179 real original9.0.3 plan sets:20 military,44 agricultural/food,
24 religious,74 artisan/production/logistics,17 civic. Full exact IDs are in
`verification/1.2.0/royal-policy/native-functions.json`; every entry is validated against the actual loaded native set,
not a copied tier/eligibility system. Culture-specific legal choices still come exclusively from RoyalConstructionCatalog.
Unknown/unclassified plans have0 automatic weight, not a guessed role. Native lumbermen are raiders and generic forges
carry patrol tags, so neither flag is used as a military classifier. Dedicated armouries/army forges/guard houses/towers
are military. Ordinary forges/wood/ore/workshops/trade are productive; farms/fisheries/hunting/food processing are food
infrastructure. Native townhalls, sub-buildings and parented structures never become automatic standalone investments.

Per-world gameplay configuration `royalNpcPolicy` defaults: ordinary justified weight1, matching personality4,
active-war military bonus6 for EVERY personality, genuinely threatened-border military bonus4. These are relative
priors among separately justified legal choices, not absolute purchase percentages.4:1 prefers specialization while
keeping alternatives; war's+6 makes defense outrank a peaceful specialist preference before need factors. A threatened
border uses actual active opponent membership/centres within the existing relation radius, without loading chunks.
When the actual war ends the exact peaceful context returns; the base personality never changes.

Existing eligible declaration and independent/directional wartime campaign draws are multiplied by capital personality:
military1.5, agricultural0.85, religious1.0, artisan0.9, general1.0. All factors are positive/configurable and the final
chance is capped at0.95; an existing zero remains zero. The modest military declaration increase works within the old
political interval, military readiness, target legality, truce, raid cooldown, direction and60% capital rules. Peace
motives and truce behavior are untouched. This is a tendency, not an order to fight or an eligibility override.
Existing OP2 `/kingdoms autonomy explain <kingdom>` reports real context, weights and factor.

Fresh focused7+7 and related existing autonomy22+22/build passed; first failed native-townhall classification baseline
is retained. No new NPC economic purchase is implemented at this checkpoint; dev.6 is not complete.
