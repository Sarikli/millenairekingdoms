## Performance, failed attempts and limits

500-site geometry cold about 30–36 ms with cache reuse; 2,000-event cold index about 55–99 ms and 24-event page about 0.65–1.03 ms/25 examined keys in focused runs. The 400-day compressed model measured evaluate p95 39.6–181.5 ms and default 2-kingdom runtime p95 114.2–477.7 ms/max 1.364 s under concurrent suite load. Synchronous strict financial/native persistence and decision reads can delay a tick. These are measured fixtures, not a 20 TPS/huge-world guarantee; new rendering does not add a global per-tick archive/chunk scan.

Current live regression also preserves the same actual original building through two upgrades with 100% final physical match, 64+128+192 fees and zero final treasury; the real 90-step first upgrade reopens from 45/90. The ordinary native 1,048-step job finishes before the waiting royal mandate, which then completes physically with one fee. These are actual original NPC/runtime observations, separate from the skipped-clock model.

Raw failures remain preserved: early bounded-NBT compilation and synthetic source-identity fixture corrections; genuine intermediate-founding and Atlas no-force baselines; first abrupt-cut diagnostic holding its own injected lock; old eager-max-schema fixtures and pre-RC.8 zero-capital/member-only/bronze-only income expectations; a fixed>100 partial cursor that could never occur in a genuine 90-step upgrade (now relative to the actual task length, still strictly partial). One later restricted-network build could not start Gradle's local lock socket; no GameTest ran, and the same offline command resumed with authorized execution permission without setup edits. Corrections retained strict field equality, malformed/authority/ledger/financial guards. No dependent reopen ran after a failed write. Successful unrelated packages were retained, not rerun to hide a failure. See progress/evidence for exact chronological attempts.
