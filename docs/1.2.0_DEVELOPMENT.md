# Development setup for By Royal Decree

Use Java **JDK** 21 (including javac), Minecraft 1.21.1 and NeoForge 21.1.259.
This branch pins Millénaire **9.0.3**, SHA-256
`5882528027ac67e8759db3926ebef36abe2300029526582f80c7a988b583ec62`.
The official downloads page links `https://www.millenaire.org/api/downloads/9.0.3~millenaire-9.0.3.jar`.
The HTTPS artifact's ZIP CRCs and embedded `META-INF/neoforge.mods.toml` version were checked.
The checksum is pinned from that official download; no separate publisher signature/checksum was advertised or assumed.
Its metadata declares NeoForge `[21.1,)`; the project's newer loader must also pass the runtime regression gate.

```bash
bash scripts/setup-millenaire.sh
./gradlew build
python3 scripts/verify-regression.py
```

curl and sha256sum are needed for the optional download helper; Python 3 is needed for the regression convenience runner.
The ignored root dependency JAR is never bundled into this addon. An existing incorrect JAR causes a checksum failure.
Never substitute another version or disable verification. Preserve old 9.0.2 JARs/worlds outside distribution artifacts.

For cloud environments whose Java tools need session proxy/CA initialization, use the already provisioned helper:

```bash
python /workspace/cloud-setup/millenaire-gradle.py build --offline
python scripts/verify-regression.py -- python /workspace/cloud-setup/millenaire-gradle.py --offline
```

This documents the current instance; it does not change saved cloud configuration. Refresh session TLS trust using the
platform's supported runtime bindings. Never dump credentials, disable TLS, or install a separate VPN.
Each task already has an isolated checkout; do not create a Git worktree unless explicitly requested.
On Linux non-ASCII project paths, `bash scripts/run-dev.sh verifyCapitals` uses an ASCII copy with the pinned dependency.
Use separate fresh worlds for different suites; retain a suite's world across its two JVMs.
