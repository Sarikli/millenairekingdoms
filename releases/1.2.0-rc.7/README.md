# 1.2.0-rc.7 — royal construction waiting queue

**Rulership → Construction → Queue** now saves one unpaid royal mandate behind the village's existing ordinary construction/upgrade. The current job continues. After completion, the same online ruler in the same dimension and loaded target/treasury allow automatic eligibility/funds revalidation and one payment at the saved price. If money/eligibility is missing, it stays unpaid and cancellable. The order survives restart; cancelling it preserves native work.
