# 1.2.0-rc.3: Construction and Shipping inside Rulership

The kingdom screen now has five main tabs. Open **Rulership → Construction** or **Rulership → Shipping** using the two buttons. Click the Rulership tab or press Esc to return; reopening starts at Rulership. Ruler/reputation/eligibility information scrolls above the fixed claim/abdication controls. Existing forms, confirmations and RC.2 stock diagnostics remain available.
